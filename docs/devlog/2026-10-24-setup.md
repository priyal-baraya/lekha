# Setting up Lekha

*2026-10-24 · Phase 1: Foundation*

## What I did

- Confirmed Python 3.13.3 on Windows 11.
- Created the project at `C:\Users\priya\projects\lekha` with `data/`, `sql/` and `docs/` folders.
- Created a virtual environment (`.venv`) and installed Streamlit 1.66.1 and Pandas 3.1.0.
- Wrote a starter `app.py` and checked that it loads at `localhost:8501`.
- Added `.gitignore` and `requirements.txt`, made the first commit and published the repository on GitHub.

## What I learned

**A virtual environment is a private copy of Python for one project.** Packages installed there don't affect other projects, and `requirements.txt` lets anyone rebuild the same setup. The `.venv` folder itself is never committed: it is thousands of files that can be rebuilt from that list.

**`python -m pip` beats plain `pip`.** It runs pip as part of the exact Python you name, so packages land in the right environment.

**`.gitignore` early prevents mistakes later.** It already excludes `.venv/` and future database files (`data/*.db`). The database will be built from scripts, so the scripts are what belong in the repository.
